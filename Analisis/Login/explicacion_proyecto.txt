GUIA SENCILLA DEL PROYECTO PIXEL STORE
=======================================

Este archivo explica de forma sencilla las partes principales de:
- login.html: estructura y contenido de la pagina.
- style.css: colores, tamaños y diseño.
- script.js: comportamiento y validaciones.

La pagina tiene tres partes principales: Inicio, Ingresar y Registrarse.


1. EXPLICACION DEL ARCHIVO HTML
================================

<!DOCTYPE html>
Indica que el documento utiliza HTML5, que es la version actual de HTML.

<html lang="es">
Es la etiqueta principal de la pagina. lang="es" indica que el idioma es español.

<head>
Contiene informacion de la pagina que normalmente no se muestra directamente.

<meta charset="UTF-8">
Permite utilizar tildes, la letra ñ y otros caracteres especiales.

<meta name="viewport" content="width=device-width, initial-scale=1.0">
Hace que la pagina se adapte a celulares, tabletas y computadores.

<title>Pixel Store | Acceso</title>
Es el texto que aparece en la pestaña del navegador.

<link rel="stylesheet" href="style.css">
Conecta el archivo HTML con el archivo de estilos CSS.
- href="style.css" indica el nombre del archivo que se va a cargar.

<body>
Contiene todo lo que el usuario puede ver en la pagina.

<header class="encabezado">
Es la cabecera o parte superior de la pagina.
- class="encabezado" conecta este elemento con los estilos de CSS que tienen ese nombre.

<h1>Pixel Store</h1>
Es el titulo principal de la pagina. h1 es el encabezado mas importante.

<nav aria-label="Navegacion principal">
Contiene los botones principales de navegacion.
- aria-label describe la navegacion para herramientas de accesibilidad.

<button class="boton-nav activo" data-seccion="inicio" type="button">Inicio</button>
Crea un boton para mostrar la seccion Inicio.
- class="boton-nav" aplica el estilo de los botones del menu.
- activo indica que este boton empieza seleccionado.
- data-seccion="inicio" guarda el nombre de la seccion que debe mostrar JavaScript.
- type="button" evita que el boton intente enviar un formulario.

<section id="inicio" class="seccion activa">
Representa una seccion independiente de la pagina.
- id="inicio" identifica la seccion de forma unica.
- class="seccion" aplica el estilo general de las secciones.
- activa hace que esta seccion se vea al comenzar.

<h2>Bienvenido a Pixel Store</h2>
Es un subtitulo. h2 se usa para los titulos de las secciones.

<p>...</p>
Es un parrafo de texto.

<button class="boton-principal cambiar-seccion" data-seccion="ingreso" type="button">
Es un boton grande para ir al formulario de ingreso.
- boton-principal aplica el estilo del boton grande.
- cambiar-seccion identifica que tambien cambia de seccion.
- data-seccion="ingreso" indica que debe mostrar la seccion ingreso.

<section id="ingreso" class="seccion">
Es la seccion donde el usuario inicia sesion. No tiene la clase activa al comienzo,
por eso empieza oculta mediante CSS.

<form id="formulario-ingreso">
Agrupa los campos y botones del formulario de ingreso.
- id permite que JavaScript encuentre este formulario.

<label for="in_email">Correo electronico</label>
Es el texto que explica que dato debe escribir el usuario.
- for conecta la etiqueta con el input que tiene ese mismo id.

<input type="email" name="correo" id="in_email" placeholder="..." required>
Es una caja para escribir el correo.
- type="email" revisa que parezca un correo electronico.
- name identifica el dato del campo.
- id identifica el campo para HTML, CSS y JavaScript.
- placeholder muestra un ejemplo dentro de la caja.
- required obliga a llenar el campo.

<input type="password" ...>
Es una caja para escribir una contraseña. Oculta los caracteres escritos.

<button class="boton-principal" type="submit">Iniciar sesion</button>
Es el boton que envia el formulario.
- type="submit" indica que el boton envia el formulario.

<p id="mensaje-ingreso" class="mensaje" role="status"></p>
Es un espacio vacio donde JavaScript muestra si el ingreso fue correcto o no.
- role="status" indica que el texto informa un cambio al usuario.

<section id="registro" class="seccion">
Es la seccion para crear una cuenta nueva.

<form id="formulario-registro">
Es el formulario que contiene los datos del nuevo usuario.

<input type="text" ...>
Permite escribir texto normal, en este caso el nombre completo.

<input type="password" id="rg_password" minlength="4" ...>
Permite escribir la contraseña.
- minlength="4" pide como minimo cuatro caracteres.

<input type="password" id="rg_confirmacion" ...>
Permite repetir la contraseña para comprobar que fue escrita correctamente.

Aqui JavaScript muestra mensajes como registro exitoso o contraseñas diferentes.

<footer>Pixel Store</footer>
Es el pie de pagina. Normalmente contiene informacion final del sitio.

<script src="script.js"></script>
Conecta el HTML con el archivo JavaScript.
- src="script.js" indica el archivo que contiene las instrucciones de comportamiento.

4. FLUJO COMPLETO DE LA PAGINA
================================

1. El usuario abre login.html.
2. La seccion Inicio aparece porque tiene la clase activa.
3. El usuario presiona Ingresar o Registrarse.
4. JavaScript oculta las demas secciones y muestra la elegida.
5. En Registro, el usuario escribe sus datos.
6. JavaScript verifica que las contraseñas sean iguales.
7. Si son iguales, los datos se guardan en localStorage.
8. En Ingresar, JavaScript compara los datos escritos con los guardados.
9. Si coinciden, muestra un mensaje de bienvenida.
10. Si no coinciden, muestra un mensaje de error.

11. FLUJO ACTUALIZADO DE LA PAGINA
==================================

1. El usuario abre login.html.
2. Se registra o utiliza una cuenta guardada en localStorage.
3. JavaScript verifica el correo y la contraseña.
4. Si los datos son correctos, el usuario va a Productos/productos.html.
5. La pagina muestra nueve productos.
6. El usuario presiona Seleccionar en uno de ellos.
7. JavaScript marca el boton y muestra el nombre en Producto elegido.
8. El enlace Cerrar sesion devuelve al usuario a login.html.

CSS es la apariencia: organiza los elementos, cambia colores, tamaños,
espacios y adapta la pagina a diferentes pantallas.

JavaScript es la logica: hace que los botones cambien de seccion, valida
las contraseñas, guarda el usuario y permite iniciar sesion.

Una frase corta para la sustentacion puede ser:
"HTML construye la pagina, CSS le da el diseño y JavaScript controla las
acciones del usuario y las validaciones del registro e ingreso."


6. OBSERVACION SOBRE EL HTML ACTUAL
====================================

Al revisar el archivo login.html actual se encontraron etiquetas repetidas
o ubicadas en un lugar incorrecto, por ejemplo un header dentro de head,
un body que aparece despues del header y algunos cierres sobrantes.

La estructura correcta debe ser:

<html>
  <head> ... </head>
  <body>
    <header> ... </header>
    <main> ... </main>
    <footer> ... </footer>
    <script> ... </script>
  </body>
</html>

Cada etiqueta debe abrirse y cerrarse en el orden correcto. Esta observacion
es importante porque una pagina puede verse parcialmente bien aunque el HTML
este desordenado. Para una sustentacion, conviene corregir esas etiquetas antes
de presentar el proyecto.
